# Пояснения

Дерево будет представлять собой набор связанных между собой узлов, реализованных через стурктуру Node. В этой структуре есть поле для значения, а также указатеои на левого и правого потомка. Значение `nil` означает отсутствие потомка у узла. 

Восстановление дерева из массива происходит по следующему правилу. Корень имеет индекс `0`, а дети узла с номером `i` индексы `2*i+1` и `2*i+2` (индекс родителя для `i > 0` равен `(i-1)/2` с целочисленным делением.). Тогда, начиная с корня, мы можем рекурсивно обработать каждый элемент массива, вставляя его на нужное место в дереве.

```go
func buildTree(data []int) *Node {
    // Строим, начинаем с корня
    return buildTreeFromIndex(data, 0)
}

func buildTreeFromIndex(data []int, index int) *Node {
    // Если индекс вышел за массив, узла в этой позиции нет
    if index >= len(data) {
        return nil
    }
    // Создаём узел и рекурсивно строим оба его поддерева
    return &Node{
        Value: data[index],
        Left:  buildTreeFromIndex(data, 2*index+1),
        Right: buildTreeFromIndex(data, 2*index+2),
    }
}
```
