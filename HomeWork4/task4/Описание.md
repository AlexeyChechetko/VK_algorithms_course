# Пояснения

Дан массив, уже представляющий бинарное дерево поиска (BST). 

Минимум находится в самом левом узле: пока есть левый ребёнок, можно перейти к меньшему значению. Максимум аналогично находится при переходах только к правому ребёнку. Создавать структуры узлов не требуется: движемся по индексам массива.

```go
func maxMinMultiplication(data []int) int {
    // Если узлов меньше 2х, то возвращаем -1
    if len(data) < 2 {
        return -1
    }
    // Начинаем с корня: он сам может оказаться крайним узлом
    minIndex, maxIndex := 0, 0
    for left := 2*minIndex + 1; left < len(data); left = 2*minIndex + 1 {
        minIndex = left
    }
    for right := 2*maxIndex + 2; right < len(data); right = 2*maxIndex + 2 {
        maxIndex = right
    }
    return data[minIndex] * data[maxIndex]
}
```

Алгоритм работает за `O(h)`, так как мы по сути спускаемся вниз 2 раза по левым элементам и правым. В худшем случае мы будем спускаться до самого низа дерева, то есть `h` шагов и так два раза.
