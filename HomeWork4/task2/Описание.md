# Пояснения

Нужно проверить, совпадают ли левое и правое поддеревья при зеркальном отражении. Используем рекурсивный обход в глубину (DFS).

```go
func isSymmetric(root *Node) bool {
    // Пустое дерево считаем симметричным
    if root == nil {
        return true
    }
    return isMirror(root.Left, root.Right)
}

func isMirror(left, right *Node) bool {
    // Два отсутствующих узла зеркальны
    if left == nil && right == nil {
        return true
    }
    // Если отсутствует только один узел, структура несимметрична
    if left == nil || right == nil {
        return false
    }
    // Значения должны совпасть, а дети сравниваются крест-накрест
    return left.Value == right.Value &&
        isMirror(left.Left, right.Right) &&
        isMirror(left.Right, right.Left)
}
```

Для пары узлов сравниваем внешних детей (`left.Left` и `right.Right`) и внутренних детей (`left.Right` и `right.Left`). 

Два поддерева зеркальны тогда и только тогда, когда оба пусты либо их корни имеют одинаковые значения, а соответствующие зеркальные поддеревья также зеркальны. Функция проверяет именно эти условия и завершает рекурсию на отсутствующих узлах, поэтому учитывает и значения, и структуру.
