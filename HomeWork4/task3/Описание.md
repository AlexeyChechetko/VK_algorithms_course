# Пояснения

Минимальная глубина — количество узлов на кратчайшем пути от корня до листа. Лист — узел, у которого нет обоих детей. Для пустого дерева ответ `0`, для одного корня — `1`.

Используем обход в ширину (BFS). Срез `level` хранит узлы текущего уровня в порядке слева направо, а `nextLevel` — очередь (массив) узлов следующего уровня.

```go
func minDepth(root *Node) int {
    if root == nil {
        return 0
    }
    level := []*Node{root}
    depth := 1
    for len(level) > 0 {
        nextLevel := make([]*Node, 0)
        for _, node := range level {
            // Путь заканчивается только в листе
            if node.Left == nil && node.Right == nil {
                return depth
            }
            if node.Left != nil {
                nextLevel = append(nextLevel, node.Left)
            }
            if node.Right != nil {
                nextLevel = append(nextLevel, node.Right)
            }
        }
        level = nextLevel
        depth++
    }
    return 0
}
```

В начале каждой итерации все узлы `level` находятся на глубине `depth`. Их дети находятся ровно на следующей глубине. Поэтому BFS проверяет глубины по возрастанию, и первый встреченный лист даёт кратчайший путь: на меньшей глубине листьев не оказалось.
