# Пояснения

Два бинарных дерева одинаковы, если у них совпадают структура и значения соответствующих узлов
```go
func isSameTree(a, b *Node) bool {
    // Если оба узла отсутствуют, в этой позиции деревья совпадают
    if a == nil && b == nil {
        return true
    }
    // Если отсутствует только один узел, структура различается
    if a == nil || b == nil {
        return false
    }
    // Сравниваем значения и соответствующие поддеревья
    return a.Value == b.Value &&
        isSameTree(a.Left, b.Left) &&
        isSameTree(a.Right, b.Right)
}
```

В отличие от проверки зеркальности, здесь левого ребёнка первого дерева сравниваем с левым ребёнком второго, правого — с правым. 

База рекурсии проверяет пустые поддеревья. Для двух непустых деревьев равенство эквивалентно совпадению корней и равенству обеих пар соответствующих поддеревьев. Функция проверяет все эти условия, поэтому учитывает структуру на любой глубине. Два пустых дерева равны.
