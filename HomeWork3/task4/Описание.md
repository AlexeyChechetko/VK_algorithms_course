# Пояснения

```go
func extraLetter(a, b string) string {
	// Ключ — буква, значение — сколько её вхождений ещё не использовано.
	counts := make(map[byte]int)
	for i := 0; i < len(a); i++ {
		// Маленькая латинская буква занимает один байт.
		// a[i] возвращает её код типа byte, который используем как ключ.
		counts[a[i]]++
	}
	for i := 0; i < len(b); i++ {
		letter := b[i]
		// Если вхождений этой буквы больше не осталось,
		// значит, встретили добавленную букву.
		// Для отсутствующего ключа map тоже возвращает 0.
		if counts[letter] == 0 {
			// Функция возвращает string, поэтому преобразуем байт в строку.
			return string(letter)
		}
		// Одно вхождение буквы из a сопоставлено с буквой из b.
		counts[letter]--
	}
	// Если добавленной буквы нет, возвращаем пустую строку.
	return ""
}
```

По условию строка `b` состоит из всех букв `a` в произвольном порядке и одной дополнительной буквы. Поэтому достаточно подсчитать количества букв, порядок не важен. Для каждой буквы `b` уменьшаем соответствующий счётчик. Единственная буква, для которой не хватит вхождения из `a`, и будет ответом. При этом добавленная буква может уже встречаться в `a`.

Например, для `a = "bbb"`, `b = "bbbb"` начальный счётчик буквы `b` равен 3. Первые три буквы уменьшают его до 0, четвёртая возвращается как лишняя.

Сортировка не используется. Ожидаемое время — `O(len(a)+len(b))`, так как строки обходим по одному разу, а операции хеш-таблицы ожидаемо занимают `O(1)`.
