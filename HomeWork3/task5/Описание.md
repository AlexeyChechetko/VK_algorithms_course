# Пояснения

```go
func twoSum(data []int, target int) []int {
	// Ключ — уже просмотренное значение, значение в хеш-таблице — его индекс.
	cache := make(map[int]int)
	for i, value := range data {
		// Ищем второе слагаемое: value + diff должно равняться target.
		diff := target - value
		// found показывает, существует ли такой ключ.
		// Проверки только index недостаточно: индекс 0 тоже допустим.
		if index, found := cache[diff]; found {
			return []int{index, i}
		}
		// Добавляем после поиска, чтобы не использовать один индекс дважды.
		cache[value] = i
	}
	// Подходящей пары нет.
	return []int{}
}
```

Функция возвращает индексы двух элементов. Для текущего элемента вычисляем единственное нужное дополнение `target-value` и ищем его сразу по ключу.

Если подходящая пара существует, она будет найдена при обработке её второго элемента: первый к этому моменту уже лежит в таблице. Текущий элемент записываем только после поиска, поэтому один индекс не используется дважды. Два одинаковых числа на разных позициях использовать можно: для `[3, 3]` и `target = 6` второе число найдёт первое и вернёт `[0, 1]`.

Если значение встречается повторно, его индекс в таблице перезаписывается. Это не мешает решению: для будущей пары достаточно любого уже просмотренного индекса с этим значением.

Ожидаемое время — `O(n)`, где `n` — длина массива: один проход и ожидаемо `O(1)` на поиск и запись в хеш-таблицу.
