# Пояснения

```go
func binarySearchSqrt(target int) int {
	// Тут проверяем, что число target >= 0, так как речь про действительные (целые) числа и операция взятия корня должна быт ьвыполнима в этом смысле
    if target < 0 {
		return -1
	}
    // Если число 0 или 1, то очевидно, что ответ - оно само
	if target < 2 {
		return target
	}
    // Для всех дургих чисел корень точно > 1 и меньше чем target / 2 + 1 (можно непосредственно проверить, записав неравенство n / 2 + 1 > sqrt(n))
	// Поэтому именно такие левая и правая граница
    left, right := 1, target/2+1
    // Дальше выполняем обычный бинарный поиск, с условием middle*middle <= target
	for left <= right {
		middle := (left + right) / 2
		if middle*middle <= target {
			left = middle + 1
		} else {
			right = middle - 1
		}
	}
	return right
}
```

Алгоритм работает за O(logn), где n - само число target, так как в его основе лежит бинарный поиск, а все остальные операции занимают O(1).
