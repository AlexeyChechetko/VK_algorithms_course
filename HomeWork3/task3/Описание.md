# Пояснения

```go
import "sort"

func feedAnimals(animals, food []int) int {
	// Если животных или еды нет, никого накормить не получится.
	if len(animals) == 0 || len(food) == 0 {
		return 0
	}
	// Сортируем потребности и порции по возрастанию.
	sort.Ints(animals)
	sort.Ints(food)
	// count — число накормленных животных и одновременно
	// индекс самого нетребовательного из оставшихся животных.
	count := 0
	for _, portion := range food {
		// Если порции достаточно, отдаём её текущему животному.
		// Порция используется один раз и не делится.
		if portion >= animals[count] {
			count++
		}
		// Если порция слишком маленькая, просто переходим к следующей:
		// ни одному из оставшихся животных она не подходит.
		if count == len(animals) {
			// Все животные накормлены, продолжать обход не нужно.
			break
		}
	}
	return count
}
```

Жадная стратегия: наименее требовательному животному отдаём наименьшую подходящую порцию. Так более крупные порции остаются для животных с большими потребностями. Если дать животному, которое требует наименьшую порцию среди всех, порцию большего размера чем, самая маленькая из привезенных (или наименьшую подходящую), то мы можем не накормить кого-то другого, так как порции не делимы.

Для `a` животных и `f` порций сортировки занимают `O(a log a + f log f)`, последующий проход — `O(a+f)`. Итоговое время — `O(a log a + f log f)`.
