# Пояснения

```go
func groupAnagrams(strs []string) [][]string {
	// Здесь храним группы слов, которые будем возвращать.
	groups := make([][]string, 0)
	// Ключ — частоты 26 букв, значение — индекс группы в groups.
	indices := make(map[[26]int]int)
	for _, word := range strs {
		// Для каждого слова создаём новый массив нулевых счётчиков.
		var key [26]int
		for i := 0; i < len(word); i++ {
			// word[i] — байт с кодом буквы.
			// Вычитание 'a' переводит код в индекс от 0 до 25:
			// 'a'-'a' = 0, 'b'-'a' = 1, ..., 'z'-'a' = 25.
			key[word[i]-'a']++
		}
		// Ищем группу с такими же количествами всех букв.
		index, found := indices[key]
		if !found {
			// Такой набор частот встретился впервые: создаём группу.
			index = len(groups)
			indices[key] = index
			groups = append(groups, nil)
		}
		// Добавляем исходное слово в найденную или созданную группу.
		groups[index] = append(groups[index], word)
	}
	return groups
}
```

Будем считать, что разрешены только маленькие латинские буквы, поэтому слово можно описать массивом из 26 частот. У анаграмм количества всех букв одинаковы, а их порядок не важен. Обратно, если все частоты совпадают, одно слово можно получить перестановкой букв другого. Поэтому массив частот однозначно определяет группу анаграмм.

Например, у `"eat"`, `"tea"` и `"ate"` в ключе по единице на позициях букв `a`, `e`, `t`, а остальные значения равны 0. Все три слова попадут в одну группу. У пустой строки все 26 счётчиков равны 0, поэтому пустые строки тоже группируются вместе. Дубликаты сохраняются.

Массив `[26]int` можно использовать как ключ `map`.

Пусть `S` — суммарная длина всех строк, `m` — число строк. Подсчёт букв занимает `O(S)`, а обработка ключей — ожидаемо `O(m)`, потому что длина каждого ключа всегда 26. Итоговое ожидаемое время — `O(S+m)`.
