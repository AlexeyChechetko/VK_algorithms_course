# Пояснения

Положим по определению, что полное бинарное дерево (или почти полное бинарное дерево) - это бинарное дерево, для которого все урвони, кроме последнего заполнены полностью, а последний заполняется слева направо. Если положить по определению, что полное бинарное дерево - это дерево, каждый узел которого либо представляет собой лист, либо имеет двух потомков (степень 2), то решение будет в некотором смысле проще. Рекурсивно проверяем что у каждого узла либо есть 2 потомка, либо узел является листом.

Каждый узел обрабатывается один раз: время `O(n)`.
