# Пояснения

Пусть `K` — число входных массивов, `m` — число непустых массивов, `N` — общее число элементов. Подготовка занимает `O(K)`, построение кучи — `O(m)`. Каждый элемент один раз извлекается и не более одного раза добавляется, размер кучи не превышает `m`. Общее время — `O(K + N*log(m+1))`, записываемое как `O(N*log K)` без учёта просмотра пустых массивов.
