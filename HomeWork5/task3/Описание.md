# Пояснения

Рассматриваем 2 различные ситуации. Поиск k-ого наименьшего и k-ого наибольшего элемента.

1. Поиск k-ого наименьшего элемента
Пример. [7, 2, 9, 0, 1], 2ой наименьший элемент - 1

Для поиска нужного элемента мы строим невозрастающую бинарную пирамиду (макс-кучу) из первых k элементов массива, таким образом сверху пирамиды будет наибольший элемент среди взятых из массива, и их k штук, все остальные из k взятых элементов в пирамиде меньше текущего на вершине, то есть это кандидат на ответ. После этого мы должны проверить оставшиеся элементы в массиве. Для этого мы проходимся по оставшимся элементам и проверяем, если элемент из массива меньше текущего максимального элемента в пирамиде, то он должен быть среди тех k элементов в пирамиде вместо вершины, поэтому мы заменяем вершину на этот элемент и вызываем Fix функцию, которая восстанавливает свойство пирамиды.

Инвариант цикла: перед каждой итерацией макс-куча содержит K наименьших элементов уже обработанной части массива. В корне находится наибольший из них — K-й наименьший среди обработанных.

2. Поиск k-ого наибольшего элемента
Пример. [7, 2, 9, 0, 1], 2ой наибольший элемент - 7

Тут аналогично строим неубывающую бинарную пирамиду из первых k элементов массива. На вершине находится минимальный элемент среди выбранных. Мы проверяем оставшиеся элементы в массиве и если текущий проверяемый элемент больше максимального в пирамиде, то меняем их и восстанавливаем свойство пирамиды.


Пусть `n` — длина массива. Время — `O(k + (n-k)*log(k))`, или `O(n*log(k))`.
