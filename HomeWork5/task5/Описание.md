# Пояснения

Высоту считаем по числу рёбер на самом длинном пути от узла до листа.

Будем считать, что высота пустого дерева равна -1, высота листа соответственно равна 0. Рекурсивно вызывая нашу функцию, мы спустимся до листов и начнем заполнять для них balance_factor, считая высоту узлов попутно и возвращая ее вверх по рекурсии, тогда для узлов выше высота будет считаться корректно, так как мы уже знаем высоту для нижележащих узлов.

Например, если слева от корня цепочка из трёх узлов, а справа один лист, коэффициент корня равен `2-0=2`. 

Корректность следует по индукции по высоте: для пустого поддерева возвращается высота `-1`, а для листа формула даёт `1 + max(-1, -1) = 0`. Если высоты детей вычислены правильно и их коэффициенты уже заполнены, формула даёт правильную высоту текущего узла и разность высот его поддеревьев. Значит, после обработки корня заполнены все узлы. 

Каждый узел обрабатывается ровно один раз, поэтому время — `O(n)`.
